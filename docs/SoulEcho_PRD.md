# 📄 产品需求文档（PRD）：【知音】AI 专属陪伴助手 (V1.2 - Web网页版)

## 1. 【文档概述】
*   **产品名称**：知音 AI (SoulEcho) - Web版
*   **项目背景**：INFP 等高敏感人群需要一个随时随地可以访问的专属树洞。网页版即开即用，降低了下载 App 的心理门槛，同时通过后台强大的知识库支持，提供高质量的情感与生活建议。
*   **产品目标**：打造一款基于 Web 的高沉浸感 AI 陪伴产品。用户可深度定制 AI 性格，AI 依托后台运营维护的专业知识库，提供情绪价值与实用建议。
*   **核心指标（KPI）**：
    *   网站日活（DAU）与月活（MAU）。
    *   平均访问时长（Session Duration）。
    *   注册转化率（从游客体验到注册保存进度的转化）。

## 2. 【用户画像与场景】
*   **典型用户**：林夕，24岁，INFP。习惯在工作间隙用电脑浏览器摸鱼，或者深夜在床上用手机浏览器浏览网页。
*   **核心使用场景**：
    *   **场景A（PC端摸鱼陪伴）**：林夕在公司用电脑办公，压力大时，切到一个极简风格的网页标签页，和 AI 朋友吐槽老板，AI 结合后台的“职场生存知识库”给出高情商的应对建议。
    *   **场景B（移动端深夜倾诉）**：睡前，林夕用手机浏览器打开书签，AI 记得她昨晚失眠，主动询问今天状态，并结合后台的“心理学知识库”引导她进行睡前冥想。

## 4. 【功能需求说明】（核心）

### 4.1 模块一：前端交互与体验 (P0)
| 功能名称 | 优先级 | 前置条件 | 操作流程/规则描述 | 异常处理/边界 |
| :--- | :--- | :--- | :--- | :--- |
| **响应式极简 UI** | P0 | 无 | 界面需极度干净，无多余广告或复杂菜单。完美适配 PC 宽屏和移动端竖屏。支持“深色模式（Dark Mode）”，迎合深夜使用场景。 | - |
| **流式对话展示** | P0 | 发送消息后 | 采用 WebSocket 或 Server-Sent Events (SSE) 技术，实现打字机效果的流式输出。支持 Markdown 渲染（加粗、列表）。 | 网络断开时，提示“连接中断，正在重连...”。 |
| **游客试用机制** | P1 | 未登录 | 允许未登录用户进行有限轮数（如 5 轮）的对话体验。达到上限后，弹出温和的注册引导：“我想记住我们的对话，可以为我创建一个专属房间吗？” | - |

### 4.2 模块二：AI 朋友性格定制 (P0)
| 功能名称 | 优先级 | 前置条件 | 操作流程/规则描述 | 异常处理/边界 |
| :--- | :--- | :--- | :--- | :--- |
| **基础档案设定** | P0 | 注册/登录后 | 设置 AI 昵称、性别、对用户的称呼。 | - |
| **性格维度选择** | P0 | 无 | 提供标签选择（如：温柔倾听、理性分析、幽默风趣）。前端将选择结果传给后端，后端组装为 System Prompt。 | - |
| **“世界观”订阅** | P1 | 无 | 用户可选择 AI 侧重的“世界观”（如：偏向心理学、偏向哲学、偏向实用主义）。这决定了后端在检索知识库时的**路由优先级**。 | - |

### 4.3 模块三：长期记忆管理 (P0)
| 功能名称 | 优先级 | 前置条件 | 操作流程/规则描述 | 异常处理/边界 |
| :--- | :--- | :--- | :--- | :--- |
| **记忆自动提取** | P0 | 对话进行中 | 后端自动识别并存储用户关键信息（喜好、近期事件）。 | - |

### 4.4 模块四：后台知识库管理 (P0 - 运营端/开发者端)
| 功能名称 | 优先级 | 前置条件 | 操作流程/规则描述 | 异常处理/边界 |

| **知识库文档上传** | P0 | 登录后台 | 支持上传 TXT/PDF/Markdown 格式的专业资料（如《非暴力沟通》、《阿德勒心理学》等）。 | 格式校验、大小限制。 |

| **知识库标签管理** | P1 | 无 | 为不同的知识文档打标签（如：职场、情感、心理学），以便在用户提问时进行精准路由检索。 | - |

## 5. 【非功能需求】
1. **跨端同步**：用户在 PC 浏览器和手机浏览器登录同一账号，聊天记录和 AI 状态必须实时同步。
2. **SEO 与访问速度**：作为 Web 产品，首屏加载速度（FCP）需控制在 1.5 秒内。首页需做基础的 SEO 优化，便于用户通过搜索引擎发现。
3. **数据隐私与合规**：虽然数据在云端，但必须在《隐私协议》中明确承诺数据不用于第三方共享。聊天记录在数据库中建议进行加密存储。

## 6. 【数据埋点建议】
1. **页面停留时间**：衡量 Web 产品的核心粘性。
2. **注册转化漏斗**：访问首页 -> 开始试用对话 -> 触发注册弹窗 -> 完成注册。
3. **知识库命中率（后端埋点）**：统计用户的提问有多少比例成功触发了后台知识库的检索并被采纳，用于指导后续知识库的扩充方向。
